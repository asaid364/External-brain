# 安卓 / Windows 只读页面框架

当前入口：记录、日报、数据与同步。复用 React + TypeScript + Vite，以浏览器窄屏和宽屏呈现两端布局，不是原生安装包。

## 运行

Node.js 20.19+ 或 22.12+，npm。

```powershell
cd D:\external-brain\apps\ui-prototype
npm ci
npm run dev -- --port 5173 --strictPort
npm run build
```

开发服务监听 0.0.0.0:5173。电脑访问 http://localhost:5173/；手机使用 `ipconfig` 中当前 WLAN IPv4，例如 http://10.3.148.220:5173/ 。地址会变化，手机需与电脑处于可互通局域网。电脑自访问成功不代表手机已可达。受阻时检查服务、Wi-Fi、设备隔离及合法的入站许可，不关闭防火墙。

## 浏览

- 记录按发生日期分组、时间倒序；摘要最多三行。查看正文、发生/首次录入时间、修改前后历史。
- 日报按日期倒序，支持日期定位、正文、来源及历史版本只读浏览。10月30日含手动版本及来源修改；29日含长文、多来源及不可用来源；27日有记录无日报；22日为空。
- 数据与同步仅说明未来职责及当前限制，不显示虚假设备、存储容量、传输进度或成功。
- 小于900px底部导航、单栏分步浏览；宽屏左侧导航、列表与详情双栏。返回保留会话内浏览位置，hash支持浏览器返回与直接定位。

## 本轮切换与边界

本轮按新授权将旧两页可写原型切换为三入口只读框架。所有展示内容均为静态合成示例，不读取、写入或清除旧 `life-ui-prototype-v1` 存储；旧数据仍可能因清除浏览器数据而丢失。旧版新增、编辑、生成、演示切换和重置入口不再提供。

没有业务按钮、可编辑正文、真实AI、设备连接、同步、备份、账号或设置中心。仅日期定位属于浏览导航。未选定正式安卓/Windows技术栈。Windows完整业务能力是后续方向，正式首版仍优先安卓业务与电脑保存同步。

不支持PWA/离线启动；页面已加载后的静态阅读不等于断网重新打开。真实安卓触摸、系统返回及网络可达尚待实机验证。
