# 项目禁止项

更新：2026-10-31。依据：[协作规则](../../AGENTS.md)、[产品需求](../product/requirements.md) 及已授权原型任务。以下汇总既有约束，不扩大为新的产品功能。

## 正式安卓记录阶段

- 不正式保存未来发生时间，不把正文未来计划当作已完成；不请求位置权限以确定时区。
- 不随手机时区变化改写旧记录当地时间，不默猜夏令时歧义，不改变首次录入时间。
- 不将草稿自动转正，不将恢复记录的编辑草稿自动合并；删除/恢复失败不出现部分状态或假成功。
- 不自动到期清理、批量删除或清空；彻底删除需独立确认，范围包括正文、历史及编辑草稿。
- 不在真实记录中默认混入合成数据，不以浏览器结果替代正式安卓安装和实机验收。
- 记录阶段原不开发日报；后续日报已单独授权，按 [日报规则](reports/behavior.md) 实施，不因此开发同步、Windows记录或把本机删除当跨设备删除。


## 数据与秘密

- 不默认读取、推断或修改 `archive/external-brain/` 个人资料；开发授权不等于个人资料授权。
- 演示与测试不使用真实生活资料，只使用合成数据。
- 不将 API Key、真实生活数据、配对凭据或本地数据库提交到仓库；日志不得输出秘密。
- 不在原型中索取或保存真实 API Key。
- 不把写入失败显示为保存成功，不在无确认的情况下清除原型数据。

## 事实与分析

- 不编造缺失活动，不把没有记录等同于没有行动。
- 日报不评价成长、效率或人格，不把计划推断为已经完成。
- 不用记录时长直接判断成长，不擅自把分析期限固定为周或月。
- 不把 AI 建议记为用户承诺，不把实现建议升级为已确认需求。
- 不静默覆盖用户手动修改的日报；不丢弃原始记录、独立时间及修改历史。
- 不添加本次范围外的专门待办、打卡或成长评分。

## 模拟与交付声明

- 不将模拟 AI、网络或同步描述为真实能力，不展示虚假的同步成功。
- 不把桌面移动视口通过描述为真实安卓输入法通过。
- 不把电脑通过本机局域网地址取得 HTTP 200 描述为手机已可访问。
- 不把已打开页面离线可保存描述为断网重新打开可用。
- 不把原型 localStorage 描述为正式安卓持久化或备份方案。
- 不把图谱推断、占位用量或未执行验证当成实现证据；未知保持未知。

## 协作、环境与授权

- 不硬编码或覆盖 OMP 设计角色的模型配置；无法调用时不擅自替换角色/模型，不声称已发生设计协作。
- 不让多个负责人同时修改公共组件与导航；先明确文件所有权。
- 不覆盖用户未完成的修改，不改无关内容。
- 未获授权不提交、不推送、不改写 Git 历史；任务清单不等于全部开发授权。
- 不为局域网排障关闭防火墙或擅自修改网络安全设置；不将开发服务暴露公网。

出现违反风险时，按 [门禁](gates.md) 停止受影响的放行并报告；其他独立且已授权工作可继续。
