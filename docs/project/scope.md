## 历史确认：正式安卓记录

记录范围为新增、补记、草稿、查看、编辑、历史、最近删除/恢复/彻底删除；原发生地点时间与时区保留，拒绝未来发生时间，已后续授权实施。详见 [行为](records/behavior.md)、[时间](records/time.md)、[删除](records/deletion.md)。

记录阶段原保留日报/数据与同步只读入口；日报现已单独授权，数据同步仍未接入。Windows记录后置，整个首版目标不删除。排除搜索、标签、复杂筛选、批量、自动清理、历史恢复、导入导出和备份。本机删除不代表跨设备删除。


## 浏览器当前范围：三入口只读框架

当前代码切换为记录、日报、数据与同步三个入口；合成内容、日期定位、详情、来源、历史和返回均为只读导航。手机底栏和分步浏览，电脑侧栏及双栏；无保存、编辑、生成、同步、配对或重置操作。旧 localStorage 不读取、不改写、不删除。下节两页可写范围属于历史交付，不是当前页面能力。

Windows 最终定位为完整客户端，后续支持记录、编辑和日报；首版仍优先安卓业务和 Windows 保存同步。本轮仅浏览器框架，不交付原生安装包或确定正式技术栈。


## 浏览器原型范围

- 随手记录和日报两页，代码位于 `apps/ui-prototype/`，采用 React + TypeScript + Vite。
- 移动端优先，覆盖 360—430px、中文长文本、记录/补记/纠错、草稿、历史及 localStorage。
- 日报由本地确定性逻辑生成；AI、网络状态和电脑同步均为模拟。
- 提供可退出的演示状态，不因切换状态删除已有数据；重置单独确认。
- 浏览器存储仅用于合成数据体验，不是正式应用的持久化、备份或跨设备同步方案。
- 支持已打开页面离线继续操作；不要求 PWA、离线启动、真实云端或原生安卓应用。
- 桌面浏览器验证已进行；真实安卓可达性、输入法、触摸和系统返回仍待验证。

## 正式产品已确认范围

- 手机端安卓，电脑端首期 Windows；先文字，语音后续增加。
- 自由活动和计划记录，保留发生时间、录入时间与修改历史。
- 用户自行配置服务地址、API Key 和模型；服务商具体兼容范围待确认。
- 事实日报、重要补充问题、用户设定期限的阶段分析与讨论后的行动计划。
- 仅本地与云端保存均在预期范围内；本地模式同一可互通局域网自动同步，电脑离线则等待。
- 首版先完成安卓记录、本地保存、真实 AI 日报与 Windows 同步，阶段分析和云端后续推进，而非从需求删除。
