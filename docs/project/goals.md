# 项目目标

更新：2026-11-01。依据：[已确认产品需求](../product/requirements.md)。本文描述目标，不代表功能已实现；状态见 [任务清单](tasks/README.md) 和 [开发状态](../engineering/status.md)。

## 产品目标（已确认）

- 在安卓手机上随时自由记录工作、学习、休息、娱乐与生活事务，积累原始事实。
- AI 整理事实日报，不在日报阶段评价成长。
- 在用户设定的期限结束后，围绕用户确认的能力与成果分析变化，发现停滞与重复问题；判断可追溯至原始记录。
- 与用户讨论并确认后续行动计划，帮助行动改变，而不只是增加记录量。
- 首轮核心价值：帮助用户发现一个原先未注意到的重复问题，并据此改变行动。此项是验证目标，不是已取得成果。
- 先由用户个人使用验证，再逐步开放其他用户。

## 阶段目标

| 阶段 | 目标 | 当前状态 |
|---|---|---|
| 两页原型 | 验证快速记录、阅读日报、补充和纠错体验 | 浏览器原型已实现；真实安卓验证待完成 |
| 最早可用版本 | 安卓文字记录、本地保存、用户配置 AI、事实日报、Windows 局域网自动同步 | 待开发；原型不等同于此版本 |
| 核心价值验证 | 自设期限、证据分析、发现重复问题、讨论下一阶段计划 | 待开发与验证 |
| 后续产品 | 云端保存选择、其他用户、语音记录 | 保留范围，后续推进 |

阶段顺序来自已确认交付方向；详细任务分解不构成自动实施全部任务的授权。正式名称、工期、预算与首轮观察期限仍待确认。

## 目标达成依据

采用 [验收标准](acceptance.md) 记录实际行为与证据，按 [门禁](gates.md) 判断是否可以进入相应交付环节。缺失证据标记待验证，不以模拟效果、记录条数或记录时长直接证明成长。
