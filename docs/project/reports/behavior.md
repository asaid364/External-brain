# 日报行为与问答

确认：2026-11-03，依据本次讨论与“采取你的设计，开始实现日报功能”。取代早期“晚上集中提问”，不表示验收通过。

## 正文与来源

- 按时间展开的客观纪实日记，不以分类为主体，不直接编辑正文、不每日确认或打卡。
- 按原当地日期归日，同日实际瞬间升序、稳定ID同刻排序，跨时区保留必要标注。不把录入时间当开始或推断时长。
- 不编造缺失活动、情绪、因果、成果，不评价成长效率人格，不把计划当完成或没记录当没行动。
- 仅发送选中日期正式保存未删除记录及适用答案，排除草稿、最近删除、其他日期与个人归档。无记录不调用AI。
- 当天可手动生成截至目前草稿，历史补记逐日手动生成/更新，不批量自动补历史。超模型范围不截断、不改日期、不删除原始事实；第一版不多轮拆分，明确限制并保留旧日报。
- 每段可核对来源和答案，保存输入版本标识；后续变化标过时，不把当前原文冒充生成时原文。

## 成果提问

- 随日报生成0—3个重要活动成果问题，查看时逐题回答/跳过，不凌晨弹窗、不独立晚间调用。不重复问已有成果，不要求休息产出，未知不等没成果。
- 答案独立关联日期、问题和活动，保留实际回答/修改时间，不改原始记录；先保存再统一手动更新，可修改、撤回、跳过、展开再答。
- 稳定活动关联用于去重，改措辞不重复追问。已存答案不因问题重生成丢失；来源变化不适用时保留待核对证据、不自动引用。
- 未保存文字明确为草稿，刷新、换日、导航不能静默丢失，不自动参与AI生成。

## 更新及删除

- 同日期一份当前日报，只保留最后成功正文，无正文历史；原始记录历史和答案证据保留。普通更新无变化不请求；显式次要重新生成确认费用后可无变化重做。
- 来源删除保留旧日报并警告，手动更新排除，旧答案不得带回。彻删原始记录不保证清除日报副本或撤回外部已接收内容。
- 全来源删除时，确认后本机移除旧正文及当前问题展示，无AI调用，保留不适用答案证据。
- 第一版不单独删除日报，无复杂版本合并/日报回收站。本轮不实现同步、导出、备份或阶段分析。
