# 日报生成、调度与AI边界

确认：2026-11-03。行为见 [正文与问答](behavior.md)。以下为确认的实现契约，验收另记。

## 配置与调用

- 第一版支持OpenAI兼容Chat Completions文本接口，自配HTTPS基础地址、模型和API Key，不承诺其他原生协议。拒绝向重定向地址转发凭据。Key使用Android Keystore保护，不明文保存/日志/导出/同步，不承诺硬件保障。
- 明确同意选中日期数据发送到所配服务及可能计费后才能调用；本地保存不等本地AI。自动默认关闭。更换配置不自动重发历史，本轮使用启动时配置，后续新请求用新配置。
- 测试连接须显式点击，仅发送最小合成内容，可能计费，不等于日报验证。真实测试不读取其他工具凭据或发送既有生活数据。
- 单次请求总超时120秒；响应超长或格式、引用不合法不作为成功，不静默截断或模拟替代。程序无法完全核实AI事实，保留来源核对。

## 任务与失败

- 同日期任务去重，输入快照固定，正文、问题、来源原子落盘才成功。普通新增/编辑期间生成结果可保存为旧快照但仍标待更新。来源删除、移出日期或删除恢复生命周期变化时不得发布迟到结果。
- 更新失败保留旧正文、问题、已存答案。返回结果尚未本地保存时，仅重试本机保存，当前进程持有结果不再请求AI。中断后先读成功结果，否则手动重试，不盲目续发。
- 暂时网络/超时/5xx/限流最多自动重试一次，使用原快照。默认等10秒；有效Retry-After至少10秒且不早于服务要求。<=60秒可自动等，>60秒结束提示手动，不截短服务要求。服务冷却跨日期和连接测试共享，点击不能绕过。
- 等完没网结束本轮，联网后手动；凭据/余额/模型/配置错误及无效输出不自动重试。超时重试可能再次计费。界面显示1/1，不承诺外部只处理一次。
- 可取消本机等待，保留旧数据，迟到结果不采用不重试，不保证外部停止或免费。

## 自动调度

- 手机当前时区次日00:10尝试前一天；允许当地00:10至01:00前启动，过窗未启动则错过；窗口内启动可完成正常请求/一次重试。
- 已有日报不自动覆盖；当天提前生成后次日也只提示变化。每日期自动尝试去重，换时区不重试已尝试日期、不自动补历史。
- WorkManager持久调度，不申请精确闹钟、电池豁免或通知权限，无准点/后台必达承诺。应用被系统限制、离线、配置无效等未生成，下次打开提示手动。仅打开页面不重放错过请求。
- 用户关自动不清现有日报；系统重启、时区变更重排后续时钟，但不盲目恢复上次请求。
