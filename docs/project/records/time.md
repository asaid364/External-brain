# 正式安卓记录：时间与时区

确认日期：2026-11-01。已确认需求；未选技术。与 [行为基线](behavior.md) 配套。

## 时间含义

- 发生时间表示记录所述事实或当时记下计划的时刻，不等于首次录入时间。
- 默认手机当前时区，不请求定位权限；补记可指定其他时区。时区默认值不证明实际地理位置。
- 保留发生地点原当地日期、时间和时区；手机跨时区后不自动改写旧记录。首次录入/修改也保留各自时区信息。
- 发生时间/时区纠正计入修改历史；首次录入时间不变。
- 按发生地点当地日期分组，组内按实际发生先后倒序，同时刻顺序稳定；跨组不承诺严格全球时间线。

## 未来与跨午夜

- 正式保存时按实际先后判断，发生时间不得晚于当前设备时刻，不能只比较不同时区钟面数字。
- 未来时间可保留在草稿中，在对应时刻到来前不能正式保存；校验失败保留输入，不自动改为当前时间。
- 正文可描述未来计划，但不代表已执行；记录时间表示当时记下计划的时刻。
- 跨午夜自由文本不自动拆分，归于用户填写的发生地点当地日期。

## 夏令时与设备变化

- 当地时间不存在：明确无效，保留输入供调整，不自动偏移。
- 当地时间重复：展示两个对应时差供用户选择，不默默猜测。
- 手机时间/时区变化不改写已有记录；保存时重新校验。
- 离线无法保证获知真实世界时间，校验依赖设备时钟；不强制联网校时，不承诺绝对准确。
