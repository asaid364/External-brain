# 正式安卓记录验收

确认日期：2026-11-01。依据 [行为](behavior.md)、[时间](time.md)、[删除](deletion.md)。下表定义标准，不预填执行结果。用户已报告基本功能手动检查，具体覆盖和逐项证据未知；本次 Mobile MCP 仅做连接验证，不认定 R01—R21 通过。分层证据见 [验证记录](verification.md)，浏览器演示不能替代正式安卓证据。

| 编号 | 场景 | 通过标准 |
|---|---|---|
| R01 | 新增后结束应用重开 | 已保存正文与发生/录入时间正确恢复 |
| R02 | 补记过去日期 | 正确归属，返回列表可定位，录入时间独立 |
| R03 | 新增草稿离开重启 | 继续同一份已写入草稿，无副本或正式空记录 |
| R04 | 编辑草稿离开重启 | 正式版本不变，草稿可继续，详情提示未保存修改 |
| R05 | 放弃编辑或改回原文 | 放弃需确认；正式内容/历史不变，无多余历史 |
| R06 | 修改正文与时间/时区 | 一次完整更新及历史，首次录入不变，前后可核对 |
| R07 | 写入失败/连点/重试 | 输入保留，不误报成功，不重复或部分更新 |
| R08 | 未来发生时间 | 按实际先后拒绝正式保存，可保留草稿，不自动改写输入 |
| R09 | 手机切换时区 | 原当地时间、时区、分组及录入/修改时区保留 |
| R10 | 删除带编辑草稿记录再恢复 | 确认说明草稿；恢复正文、历史和草稿，草稿不转正 |
| R11 | 彻底删除后重启 | 独立确认不可恢复，正文/历史/草稿不再可读 |
| R12 | 删除/恢复/彻底删除失败重试 | 保持原状态，不假成功，不部分清除或重复 |
| R13 | 离线无电脑 | 全部本机记录操作可完成 |
| R14 | 中文输入法与长文 | 真机光标、选取、换行、滚动、保存和返回可用，无静默截断 |
| R15 | 数据读取失败 | 明确错误，不用空数据覆盖旧内容 |
| R16 | 构建安装运行 | 正式安卓包可安装运行，构建与检查有实际证据 |
| R17 | 夏令时异常 | America/New_York 2026-03-08 02:30无效；2026-11-01 01:30选择-04:00/-05:00，不猜测或偏移；设备测试时钟须晚于被测时间，避免与未来校验混淆 |
| R18 | 跨午夜/同刻/设备变化 | 不拆分文本，同刻排序稳定；保存重新校验，旧数据不改写，时钟局限明确 |
| R19 | 最近删除策略 | 只读、展示原发生与删除时间；无自动清理/批量/清空；恢复不改首次录入 |
| R20 | 首次启动与其他入口 | 真实记录无默认合成数据；日报及数据同步只读标注未接入，无业务或假成功 |
| R21 | 草稿写入/放弃清除失败 | 不谎报已保留/放弃；离开提示风险，正式版本不变 |

## 执行要求

逐项验证后，运行新增—补记—编辑—删除—恢复闭环，再总验收。每项记录版本、设备环境、步骤、预期、实际、证据、结论与限制，不预填通过，不缩小用例掩盖失败。演示测试只用合成数据。

参照 [项目验收总则](../acceptance.md)、[门禁](../gates.md)。安卓记录阶段通过不等于包含真实AI和Windows同步的整个首版放行。
