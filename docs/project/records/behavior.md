# 正式安卓记录：行为基线

确认日期：2026-11-01。来源：本轮需求讨论及三组事项审阅确认。本文是已确认需求，不是技术方案或开发授权；正式功能尚未实现。

## 范围与入口

交付正式安卓记录功能，不能以浏览器原型替代。保留记录、日报、数据与同步三个一级入口；后两者仅保留明确标注未接入的只读框架，不开发业务。真实记录与合成演示分离，不默认混入示例。Windows记录业务后置。

记录内部包括列表、新增/编辑、详情、最近删除，不增加第四个一级入口。

## 列表与详情

- 按发生地点当地日期分组，日期倒序；同组按实际发生先后倒序，同时刻稳定排序。跨日期组不保证严格全球时间线。
- 条目显示发生时间、正文前2—3行与必要的补记/已修改说明，不要求标题；必要时说明时区。
- 返回列表保留位置。详情正文完整、保留换行，随后显示发生时间、首次录入时间；有修改时显示最近修改时间与可展开历史。
- 历史展示修改时间、前后正文及发生时间/时区变化，按修改时间倒序，只读，不恢复历史版本。

## 新增与修改

- 自由文字可写活动、想法和计划，不拆成待办，不推断计划完成。
- 发生时间默认当前时间，可补记；校验见 [时间规则](time.md)。首次正式保存确定首次录入时间。
- 保存成功进入详情，返回列表定位到记录所在日期；新增成功清除对应草稿，失败保留正文与时间。
- 编辑可改正文、发生时间与时区，首次录入时间不可改；一次保存构成一次历史，无实际变化不产生历史。
- 保存前正式版本不变；失败不改变正式正文/历史，保留草稿。连续操作或重试不得创建副本或重复历史。
- 空白正文不创建记录，不静默截断；不擅设较小字数上限，必要限制另行说明确认。有效空格与换行保留。

## 草稿与离开

- 一份新增草稿，每条记录最多一份编辑草稿，与正式版本分开。
- 再次新增继续原草稿；再次编辑恢复该记录草稿，标明尚未正式保存。详情展示正式版本并提示可继续编辑。
- 空白新增不形成有效草稿，无更改不产生编辑草稿；改回正式内容不提示未保存修改。
- 普通返回保留草稿，不自动正式保存；输入法显示时先遵循安卓正常收起行为。可靠保留时轻量提示，不每次弹框。
- 草稿保留失败明确风险，允许继续编辑；坚持离开时确认可能丢失，不假称已保留。
- 主动放弃有效草稿需确认；放弃编辑草稿不影响正式记录/历史。清除失败不显示已放弃。
- 后台尽量保留草稿；重启先到列表，提供继续新增草稿入口，详情提示各自编辑草稿。
- 仅承诺已成功写入内容可恢复，突发断电前尚未写入的最后输入不保证保留。

## 可靠性与视觉

本机操作不依赖网络、AI或电脑。读取失败不能用空数据覆盖旧内容；失败不误报成功，不出现正文、历史、草稿部分更新。不承诺卸载、清除数据或设备损坏后的恢复。

中文输入、长文、选取和光标编辑可用；主要操作清楚，破坏性操作区分；输入法弹起保存可达，状态不只靠颜色。由OMP当前设计角色负责视觉交互，集成后实际复核；本轮不选择框架或存储技术。
