# 正式安卓记录：删除与恢复

确认日期：2026-11-01。已确认采用可恢复删除，与 [行为基线](behavior.md) 配套。

| 操作/状态 | 规则 |
|---|---|
| 删除 | 详情发起，二次确认后移入最近删除，不直接永久清除 |
| 最近删除 | 记录内部次级页；展示摘要、原发生时间及删除时间，不增加一级导航 |
| 正常列表 | 不展示已删除记录 |
| 有编辑草稿 | 删除前明确提醒；正式版本、历史、草稿一起保留 |
| 查看已删除记录 | 只读；说明存在的草稿，恢复后才能编辑 |
| 恢复 | 正文、发生/首次录入时间、历史与草稿一起恢复；按发生时间归回并提供查看入口 |
| 恢复草稿 | 仍是未保存编辑，不自动合并或转正 |
| 彻底删除 | 独立确认不可恢复，同时清除正文、历史与关联编辑草稿 |
| 操作失败 | 保持原状态，不显示成功；允许重试，不产生副本或部分清除 |

不自动到期清理、不批量删除、不一键清空。首次录入时间不因删除/恢复改变。永久清除指应用数据中的记录及关联内容不再可读，不承诺物理介质取证级擦除。

本阶段仅本机操作，不实现日报引用更新、跨设备删除或同步协议；不得将本机删除成功说成所有设备都已删除。后续接入其他能力须单独确定关联规则。

验收见 [R10—R12及R19](acceptance.md)，技术方案与实现尚未开始。
